USAGE EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

Minimal Example:
  from ir_widget import IRWidget
  widget = IRWidget(file_path="molecule.log")
  widget

With Sample Data:
  from ir_widget import IRWidget
  from sample_data import get_sample_data
  
  data = get_sample_data("ACETONE")
  widget = IRWidget()
  widget.load_data(data['frequencies'], data['intensities'], data['formula'])
  widget

Customization:
  widget.broadening = "gaussian"  # or "lorentzian", "none"
  widget.fwhm = 25.0             # peak width in cm⁻¹
  widget.x_min = 500             # wavenumber range
  widget.x_max = 3500
  widget.show_table = True
  widget.show_plot = True
